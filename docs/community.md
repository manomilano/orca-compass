# Community and support

Find guidance, report a problem, or check licensing and attribution.

## Get help

For questions and how-to guidance, start with the [README](https://github.com/manomilano/orca-compass#readme) and the [user guide](./guide.md).

## Report bugs and request features

Use the [new issue forms](https://github.com/manomilano/orca-compass/issues/new/choose)
to report bugs or request features. For bugs, include:

- a minimal reproduction;
- the command you ran;
- what you expected;
- the relevant part of `orcacompass status --json`, with personal paths and
  account details removed.

For larger changes, open an issue describing the problem and proposed behavior.
See [Contributing](./contributing.md) for more details.

## Report a security vulnerability

Report security vulnerabilities privately using [GitHub's private vulnerability report](https://github.com/manomilano/orca-compass/security/advisories/new). Follow the [security policy](https://github.com/manomilano/orca-compass/blob/main/SECURITY.md), and do not disclose exploit details in a public issue or pull request.
